The CLI asks about the app's features: Inglorious UI and its theme, a mobile app, routing, page transitions, icon packs (Material Symbols, Font Awesome, Lucide) and translation into several languages, with a flag for each. For lit-html apps it generates the matching source: an app shell, pages, routes, a store, catalogues and a language picker, in JavaScript or TypeScript, already formatted and lint-clean. PWA projects no longer come out with misformatted `vite.config` and `main` files.
