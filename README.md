# Inglorious Forge

> One entity-based model for web apps, pre-rendered sites, generative UI and games.

Inglorious Forge is a JavaScript framework built on a single idea: an application's state is a store of plain entities, and everything that happens to them is an event. The same store drives a web framework with its own design system, charts, motion and i18n; sites rendered on the server, at build time or on request; interfaces generated by language models; and a 2D game engine with multiplayer synchronization.

There are no signals, no component state and no compiler to learn. Types are plain objects of event handlers and a `render`, and the whole UI re-renders from the store, with [lit-html](https://lit.dev/docs/libraries/standalone-templates/) updating only what changed in the DOM.

## What's in it

**Foundation**

- [`@inglorious/store`](https://inglorious.dev/store/): the entity store every other package builds on, Redux-compatible, with async helpers and state machines.
- [`@inglorious/react-store`](packages/react-store): hooks and a provider to use the store from React.

**Web apps**

- [`@inglorious/web`](https://inglorious.dev/web/): the web framework, with a router, forms, browser sensors and testing utilities.
- [`@inglorious/ui`](https://inglorious.dev/ui/): the design system: controls, data grids, chats, dialogs and more, in six themes.
- [`@inglorious/charts`](https://inglorious.dev/charts/): SVG charts, from bars and lines to pies, scatter, radar and radial.
- [`@inglorious/motion`](https://inglorious.dev/motion/): CSS-first animation, layout transitions and presence.
- [`@inglorious/i18n`](packages/i18n): translations driven by a store entity.
- [`@inglorious/ag-grid`](packages/ag-grid): AG Grid, with no adapter.
- [`@inglorious/supabase`](packages/supabase): Supabase, starting with Realtime changes that keep entities live.
- [`@inglorious/firebase`](packages/firebase): Firebase push notifications and analytics, in the browser and in Capacitor apps.

**Sites**

- [`@inglorious/ssx`](https://inglorious.dev/ssx/): pages rendered on the server, statically at build time or on each request, then hydrated, with file-based routes and API routes.

**Generative UI**

- [`@inglorious/openui`](packages/openui): renders [OpenUI Lang](https://openui.com/docs/openui-lang) answers from a language model with Inglorious UI, as they stream in.

**Authoring**

- [`@inglorious/vite-plugin-jsx`](packages/vite-plugin-jsx) and [`@inglorious/vite-plugin-vue`](packages/vite-plugin-vue): write templates in JSX or Vue-like syntax, compiled to lit-html.
- [`@inglorious/vite-plugin-hmr`](packages/vite-plugin-hmr): keeps the store's state across hot updates.

**Games**

- [`@inglorious/engine`](https://inglorious.dev/engine/): a 2D game engine on the same entity model, with [`renderer-2d`](packages/renderer-2d) for the Canvas and [`renderer-react-dom`](packages/renderer-react-dom) for React.
- [`@inglorious/server`](packages/server): real-time state synchronization over WebSockets, for multiplayer games and collaborative apps.
- [IngloriousScript](packages/babel-plugin-inglorious-script): a JavaScript superset with vector operators, for game logic.

**Tooling**

- [`@inglorious/create-app`](packages/create-app) and [`@inglorious/create-game`](packages/create-game): project scaffolders.
- [`@inglorious/eslint-config`](packages/eslint-config): shared lint presets.

## Getting started

Scaffold a project, picking a web app or a pre-rendered site, JavaScript or TypeScript, and the parts you want:

```bash
npm create @inglorious/app@latest
```

Or see the model in a few lines: a type handles events and renders its entities, and the app mounts the store.

```javascript
import { createStore } from "@inglorious/store"
import { html, mount } from "@inglorious/web"

const types = {
  Counter: {
    increment(entity) {
      entity.value++
    },
    render(entity, api) {
      return html`<button @click=${() => api.notify(`#${entity.id}:increment`)}>
        Clicked ${entity.value} times
      </button>`
    },
  },
}

const store = createStore({
  types,
  entities: { counter: { type: "Counter", value: 0 } },
})

mount(store, (api) => api.render("counter"), document.getElementById("root"))
```

## Status

Forge is used in real projects, and is still evolving: until things settle, breaking changes may happen between minor versions, and each one is described in its package's changelog. If you find a sharp edge, please [open an issue](https://github.com/IngloriousCoderz/inglorious-forge/issues).
