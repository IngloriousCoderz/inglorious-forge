Inglorious Forge — Open Source

Build less.
Ship more.
Own it.

One entity-based model for web apps, pre-rendered sites, generative UI and games. State is a store of plain entities, everything that happens to them is an event, and the whole UI renders from it. No proxies, no signals, no magic.

Inglorious Forge is the open-source monorepo behind every @inglorious package. Inglorious Web is its web framework. Inglorious Coderz is the company that makes them.
