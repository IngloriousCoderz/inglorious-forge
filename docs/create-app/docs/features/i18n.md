# Translations

| Question           | Flag                                           |
| ------------------ | ---------------------------------------------- |
| Translate the app? | `--i18n` / `--no-i18n`                         |
| Which languages?   | `--languages=en,it` (the first is the default) |

`--i18n` adds [`@inglorious/i18n`](https://inglorious.dev/web/featured/i18n): one JSON catalogue per language in `src/i18n/locales/`, a language picker, and the locale in a store entity that remembers the choice. The app mounts once the starting language has loaded, so the first render is already translated.

The generated texts, including the sign-in screen, the prompts and the update page, come translated into:

| Code | Language  |
| ---- | --------- |
| `en` | English   |
| `it` | Italiano  |
| `fr` | Français  |
| `de` | Deutsch   |
| `es` | Español   |
| `pt` | Português |
| `ja` | 日本語    |
| `ar` | العربية   |

Without `--i18n`, the texts are English and live in the code.
