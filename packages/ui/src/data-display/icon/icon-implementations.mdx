# Icon Implementations

`Icon` draws icons as inline SVG. No icon font is loaded, so nothing waits on a download and only the icons an app imports end up in its bundle.

## Icon sets

Any set published by [Iconify](https://icon-sets.iconify.design/) works in the same way: install the set, import each icon as its own module, pass it as `icon`.

```bash
pnpm add @iconify-icons/material-symbols
```

```javascript
import { Icon } from "@inglorious/ui/icon"
import arrowBack from "@iconify-icons/material-symbols/arrow-back"
import settingsOutline from "@iconify-icons/material-symbols/settings-outline"

Icon.render({ icon: arrowBack, size: "lg" })
```

The icon is one em square, so `size` sets it, and it takes the color of the text unless `color` says otherwise.

| Set                                                           | Package                                                 | Example imports                                                               |
| ------------------------------------------------------------- | ------------------------------------------------------- | ----------------------------------------------------------------------------- |
| [Material Symbols](https://fonts.google.com/icons)            | `@iconify-icons/material-symbols`                       | `settings` (filled), `settings-outline`, `settings-rounded`, `settings-sharp` |
| [Font Awesome 7 Free](https://fontawesome.com/search?ic=free) | `@iconify-icons/fa7-solid`, `fa7-regular`, `fa7-brands` | `user`, `heart`, `instagram`                                                  |
| [Lucide](https://lucide.dev/icons/)                           | `@iconify-icons/lucide`                                 | `user`, `settings`, `heart`                                                   |

The variant is part of the name, not a prop: in Material Symbols the plain name is the filled icon and `-outline` the outlined one. Font Awesome's icons are under CC BY 4.0, which asks for attribution.

## Glyphs and custom markup

Without `icon`, `children` is shown instead: an emoji, a Unicode glyph, or SVG of your own.

```javascript
Icon.render({ children: "★", size: "lg" })
```

The Unicode glyph explorer is in the **Data Display/Icon/Unicode** story.

## Direction

An icon that points along the line, such as a back arrow or a chevron, should point the other way in right-to-left text. Pass the direction of the text it sits in; with `@inglorious/i18n`, that is the i18n entity's `dir`:

```javascript
Icon.render({ icon: arrowBack, direction: api.getEntity("i18n").dir })
```

## Accessibility

- An icon is decorative by default: it is hidden from assistive technology.
- An icon that means something on its own, with no text next to it, takes a `label`: it is then announced as an image with that name. On an icon-only button, label the button instead.
- Do not rely on an icon's shape alone for state; pair it with text or color contrast.
