# Security Policy

## Supported versions

Security fixes go into the latest release of each `@inglorious/*` package. Older major versions are not patched: upgrade to the current one.

The packages under `packages/` are in scope. The examples, docs sites and benchmarks in this repository are demos, not supported software.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through [GitHub's security advisories](https://github.com/IngloriousCoderz/inglorious-forge/security/advisories/new).

Include the affected package and version, what an attacker can do, and the steps or code to reproduce it.

What to expect:

- An acknowledgement within 7 days.
- An assessment within 14 days: whether we consider it a vulnerability, and how severe.
- For accepted reports, a fixed release as soon as it is ready, published with a security advisory that credits you unless you prefer otherwise.

There is no bug bounty.
